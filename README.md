# **Digital Garden**

A minimalist and customizable web app for organizing ideas through themes and notes. Built with **PHP 8 (procedural)**, **MySQL**, **TailwindCSS**, **HTML5**, and **JavaScript**.

## Overview

Digital Garden gives each user a private space — their own “digital garden” — where they can organize thoughts using **Themes** (categories) and **Notes** (content blocks).
The project focuses on simplicity, security, and a lightweight, modern UI.

## Features (WIP)

* User registration & login
* Secure session management
* CRUD for Themes (name, color, tags)
* CRUD for Notes (title, content, importance, theme)
* Client-side + server-side validation
* Responsive layout using TailwindCSS

> *More features will be added progressively as the project grows.*

## Tech Stack

* **PHP 8** (procedural)
* **MySQL / SQL**
* **TailwindCSS**
* **JavaScript**
* **HTML5**
